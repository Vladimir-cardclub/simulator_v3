# Card.Club · Partner Journey

Интерактивный симулятор первых 90 дней B2B-партнёрства с [Card.Club](https://card.club). Не калькулятор, а виртуальный тест-драйв: проживаешь путь от спящей базы контактов до стабильного второго денежного потока, принимая решения и видя цифры.

**Live-демо:** [vladimir-cardclub.github.io/gamefication/cardclub_partner_journey_v4_1.html](https://vladimir-cardclub.github.io/gamefication/cardclub_partner_journey_v4_1.html)

---

## Зачем это нужно

Партнёрская программа Card.Club — простая по сути: рекомендуешь карту → клиент её выпускает → получаешь фиксированное вознаграждение. Но «простую сути» сложно продать в B2B-переписке. Турагентствам, визовым центрам, агентствам недвижимости и блогерам нужно увидеть и потрогать сценарий, прежде чем подписаться.

Симулятор делает три вещи:

- **Снимает возражения до того, как они прозвучали** — пока человек проходит шаги, он сам отвечает себе на вопросы про цену, конверсию, объём дохода.
- **Показывает результат на собственных цифрах** — слайдер базы, выбор сегмента, выбор стратегии. Эффект Барнума: «цифры лично про меня».
- **Доводит до личного контакта** — финал готовит предзаполненное сообщение в Telegram Владимиру, чтобы первый шаг занял один тап.

---

## Как это работает

Шесть экранов, тёмная премиум-эстетика, плавные переходы. На каждом шаге игрок принимает решение, которое влияет на финальный прогноз.

| Шаг | Что происходит |
|---|---|
| **1. Welcome** | «Ваш актив — это база контактов». Объяснение продукта + блок «что вы упускаете прямо сейчас». |
| **2. Персонализация** | Выбор сегмента (туризм / визы / недвижимость / образование / блогер) + слайдер базы 50–50 000. |
| **3. Активация** | Выпуск карты себе для тест-драйва: ИИ-сервисы или бизнес-софт. Ачивка «Самотестер». |
| **4. Цена и стратегия** | Слайдер $20–$200, сравнение с банковскими картами Казахстана/Кыргызстана, три стратегии (Премиум 6% / Масс 12% / Пакет 22%). |
| **5. Действия и рост** | Цикл «забрать материалы → сделать касание базы». Анимированный график дохода + live-лента партнёрской сети. |
| **6. Финал** | Прогноз 3 мес / 12 мес. Шкала «что можете себе позволить» от кофе до личного водителя. Reality break с упущенным доходом. **Письмо себе через 60 дней** — копируется, отправляется в Telegram или на email. CTA → написать Владимиру. |

## Геймификация (Octalysis · 90% White Hat / 10% Black Hat)

- **Миссия** — монетизация спящего актива.
- **Развитие** — линейные ранги STARTER → PRO → EXPERT → ELITE, XP за действия.
- **Творчество** — выбор сегмента, цены, стратегии. Каждый выбор реально меняет цифры.
- **Собственность** — «ваш путь», «ваша база», «моё обещание себе» (капсула времени с localStorage-напоминанием через 60 дней).
- **Социум** — live-лента активности других партнёров.
- **Любопытство** — плавные cubic-bezier переходы, разблокировка достижений.
- **Потеря** — динамический Reality Break в финале (упущенный доход в день).

Чёрная шляпа включается только в финале — до этого опыт строится на внутренней мотивации, чтобы не сломать эффект сверх-оправдания.

## Технические требования

- Один автономный HTML-файл, без зависимостей (кроме шрифтов с Google Fonts).
- Ванильный JS / CSS. Никаких сборщиков, фреймворков, npm.
- ~95 KB. Загружается мгновенно.
- Адаптивная вёрстка под мобильные.
- localStorage для запечатывания письма и напоминания при возврате.
- `prefers-reduced-motion` уважается.

## Структура файла

Один HTML, внутри — три секции:

```
<style>     — токены дизайна, экраны, компоненты, анимации
<body>      — 6 экранов + HUD + ачивка-попап + модалка возврата
<script>    — State, Router, Calc, UI helpers, привязка событий
```

Архитектура JS модульная по назначению: `State` (состояние игрока), `Calc` (формулы), функции по экранам (`initWelcome`, `renderSegments`, `bindPriceSlider`, ...), `goToStep` как роутер.

## Математика

```js
cut          = price × 0.5                        // партнёрская комиссия
ltv          = 1.15 + (materialsClaimed ? 0.10 : 0)
cards90d     = baseSize × conversion × ltv
income90d    = cards90d × cut
income12mo   = income90d × 4 × 1.35               // компаундинг рефералов и реактивация
dailyLoss    = income12mo / 365                   // для reality break
```

Цифры консервативные — реальные кейсы могут давать больше.
